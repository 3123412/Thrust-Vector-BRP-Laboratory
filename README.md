# Вектор Тяги: Лаборатория BRP

Сборка и испытания ракет на Unity. 50 типов деталей, 20 миссий и свободный режим. Управление на ПК и через OpenXR.

Unity 6000.6.7f1. Откройте сцену `Assets/BRP/Scenes/Laboratory.unity` и нажмите Play. Ангар, ракета, интерфейс и эффекты сохранены в проекте.

Перетаскивайте детали мышью. ПКМ вращает камеру, R поворачивает деталь. В полёте: Shift/Ctrl меняют тягу, Space переключает ступень, P раскрывает парашют, M открывает карту, F открывает команды.

Сборка EXE: `BRP → Build Windows`. Файлы появятся в `Delivery/Windows`.
