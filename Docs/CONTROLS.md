# Управление

Игра сама ищет OpenXR-шлем при запуске. Подключите шлем, контроллеры и OpenXR runtime заранее. Если шлем не найден, игра откроется в режиме ПК.

Изменения подстройки VR и учебного стенда описаны по текущему коду. Новый прогон Play Mode ещё впереди; проверка этих функций в физическом шлеме не выполнена.

## ПК

| Действие | Управление |
|---|---|
| Добавить модуль | Перенести карточку из каталога или нажать на неё |
| Переставить узел | Выбрать модуль, нажать «Разблокировать» и перенести подсборку |
| Повернуть переносимую деталь | R |
| Осмотреть ракету / приблизить | ПКМ / колесо мыши |
| Изменить масштаб сборки | − / + над верстаком |
| Отменить / повторить правку | Ctrl+Z / Ctrl+Y |
| Удалить выбранный модуль | Delete |
| Увеличить / уменьшить тягу | Shift / Ctrl или кнопки тяги |
| Выключить двигатель | X |
| Переключить ступень | Space |
| Наклон / крен | W/S, A/D / Q/E |
| Двигатели сближения | I/K, J/L, U/O |
| Парашют / воздушный тормоз | P / B |
| Карта / ускорение времени | M / T |
| Команды полёта | F |
| Аварийное спасение | Backspace |

Голубой маркер показывает свободное крепление. Для подробного паспорта нажмите на название выбранного модуля справа.

## VR

Луч выбирает кнопки, хват переносит свободные детали. Установленный узел сначала нужно разблокировать. В ангаре доступна телепортация. Чтобы изменить размер ракеты, отпустите детали, закройте диалоги, удерживайте основные кнопки обоих контроллеров и разводите или сводите руки. При захваченной детали масштабирование отключено.

Для работы сидя или стоя откройте настройки и нажмите «Подстроить рабочее место». Команда выравнивает направление XROrigin и ставит камеру глаз на высоту 1,65 м у верстака. Подстройка сохраняется после возвращения из полёта в мастерскую. Перед подстройкой отпустите деталь; в полёте она недоступна. Сохранение между запусками игры не предусмотрено.

При потере фокуса окна сбрасываются команды поворота и двигателей сближения. После возвращения в игру отпустите кнопки контроллеров, затем нажмите их снова.

В полёте:

- Правая основная кнопка переключает ступень, дополнительная раскрывает парашют.
- Левая основная кнопка открывает и закрывает карту, дополнительная открывает команды.
- Правый триггер и стик управляют наклоном. Правый хват и стик меняют тягу.
- Левый триггер и стик включают двигатели сближения. Левый хват переключает вертикальную ось перемещения.

На контроллерах с A/B/X/Y основные кнопки соответствуют A и X, дополнительные соответствуют B и Y.

На открытой карте:

- X на левом контроллере закрывает карту.
- A на правом контроллере переключает режим карты.
- B на правом контроллере выбирает следующую планету.
- Правый стик вращает обзор.
- Вертикальная ось левого стика меняет приближение.

В VR вы наблюдаете полёт из неподвижной станции в объёмной сцене. Можно свободно смотреть вокруг: камера головы не поворачивается вслед за ракетой. Карта появляется на экране перед наблюдателем.

## Обучение и звук

Начните программу испытаний. Инструктор озвучивает шаги и подсвечивает нужные детали, крепления и кнопки. «Повторить» снова включает текущую реплику. Громкость инструктора и музыки меняется отдельно в настройках.

«Показать ближе» открывает учебный стенд для текущего шага. Перетаскивайте модель для вращения, меняйте приближение колесом или кнопками «−» и «+». Кнопки со стрелками поворачивают модель, «Сброс» возвращает исходный обзор. В VR используйте луч и кнопки стенда.

«Деталь» показывает выбранный модуль отдельно. «Соединение» показывает его вместе с узлом текущей сборки и креплением. Стрелка обозначает направление монтажа, кольцо отмечает место соединения. «Пауза» останавливает анимацию; ползунок позволяет вручную пройти монтаж или снятие детали. Это демонстрация: настоящая сборка при осмотре не меняется.

Читайте «Зачем этот модуль», «Что сделать» и «Если не получается»: здесь указаны назначение, действие и диагноз текущего шага. «В каталоге» переводит к нужной детали, «К сборке» закрывает стенд. В обучении сохранены 98 WAV-реплик мужского голоса Aidar.

## Первый запуск и карта

В «Чертёж» выберите учебную ракету. «Испытать» запускает огневой стенд, «На космодром» начинает полёт. Для выхода на орбиту возьмите орбитальный или возвращаемый образец и включите «Программу выведения».

На карте доступны своя орбита, система Земля-Луна и обзор планет. «К полёту» возвращает внешний вид. Верхнее меню скрыто во время полёта и открывается кнопкой «Панели».

«Возвращение капсулы» выполняет торможение, отделяет капсулу и выпускает парашюты при безопасной скорости. Для стыковки откройте F → «Орбитальный стенд» и включите помощник сближения. Узлам нужны расстояние до 0,6 м, скорость до 0,2 м/с и угол до 5°.

## Посадка на Луну

В свободном режиме откройте карту или команды полёта. «Лунная экспедиция» начинает отдельный сценарий с орбиты Луны на высоте 50 км. «Тренировка посадки» начинает спуск с высоты 5 км. В обоих случаях включается посадочный помощник. Это стартовые условия сценария; перелёт от Земли не выполняется.

На Луне тормозите двигателем: парашюты и аэродинамические рули там не работают. Высота над опорами показана в метрах, рядом указана вертикальная скорость. Помощник можно отключить для ручного спуска. После посадки закройте окно результата крестиком и увеличьте тягу для повторного взлёта.

## Цвет и наклейки

Выберите модуль и откройте «Облик». Настройте основной цвет, акценты и покрытие. Для маркировки выберите эмблему, введите надпись и задайте размер и поворот. Кнопка «Клавиши» открывает экранную клавиатуру для ввода лучом в VR.

Предпросмотр показывает изменения до сохранения. «Отменить изменения» возвращает прежний вид. После «Сохранить облик» доступны обычные отмена и повтор. Цвета и наклейки сохраняются вместе с чертежом; при выборе всего корпуса наклейка остаётся на показанном модуле.
