# Управление

## ПК

| Действие | Управление |
|---|---|
| Добавить деталь | Перенести карточку из каталога или нажать на неё |
| Перенести установленный узел | Выбрать деталь → Разблокировать |
| Повернуть деталь | R во время переноса |
| Вращать камеру | Удерживать ПКМ |
| Приблизить | Колесо мыши |
| Изменить размер на верстаке | Кнопки − / + над ракетой |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |
| Удалить | Delete |
| Изменить тягу | Shift / Ctrl или кнопки тяги |
| Отключить тягу | X |
| Следующая ступень | Space |
| Наклон / крен | W/S, A/D, Q/E |
| Двигатели сближения | I/K, J/L, U/O |
| Парашют | P |
| Воздушный тормоз | B |
| Орбитальная карта | M |
| Скорость времени | T |
| Команды полёта | F |
| Аварийное спасение | Backspace |

Установленные детали блокируются. Кнопка «Разблокировать» снимает выбранную подсборку вместе с дочерними деталями. Голубой маркер показывает свободный узел крепления.

## VR

Подключите совместимый OpenXR runtime, шлем и контроллеры. В главном меню выберите «Подключить VR».

- Захват переносит свободные детали. Луч выбирает кнопки интерфейса.
- Телепортация использует штатное управление XR Origin.
- Удерживайте основные кнопки обоих контроллеров и разводите руки, чтобы менять размер ракеты на верстаке.
- Левая дополнительная кнопка открывает меню.
- В полёте правая основная кнопка переключает ступень, правая дополнительная раскрывает парашют. Левая основная переключает карту.
- Правый триггер и правый стик управляют наклоном. Правый хват и стик меняют тягу.
- Левый триггер и левый стик управляют двигателями сближения. Левый хват переключает вертикальное перемещение.

На контроллерах с раскладкой A/B/X/Y основные кнопки — A и X, дополнительные — B и Y. Полёт наблюдается на мониторе лаборатории; положение головы не привязано к вращению ракеты.

## Первый полёт

Откройте «Чертёж» и выберите учебную ракету. Кнопка «Испытать» удерживает её на стенде, «На космодром» запускает свободный полёт.

Для орбиты выберите орбитальную или возвращаемую конструкцию и включите «Программу выведения». Она управляет наклоном, тягой и отделением первой ступени. Для ручного полёта отключите программу через ту же кнопку.

Груз отделяется отдельной командой. «Возвращение капсулы» выполняет торможение, отделяет капсулу и раскрывает парашюты при безопасной высоте и скорости. Возвращаемая конструкция содержит щит, регистратор и систему спасения.

Для сближения откройте F → «Орбитальный стенд». Команда «Помощник сближения» использует двигатели ориентации. Стыковке нужны противоположно направленные порты, расстояние до 0,6 м, относительная скорость до 0,2 м/с и угол до 5°.
