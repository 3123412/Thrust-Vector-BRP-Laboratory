# План и состав проекта

«Вектор Тяги: Лаборатория BRP» — конструктор ракет с испытаниями на ПК и управлением через OpenXR.

## Этапы

1. Разобрать критерии PDF и концепцию DOCX. Зафиксировать 50 типов деталей, 20 миссий и свободный режим.
2. Создать модели деталей, ангар, стенд, космодром и окружение в Blender. Сохранить исходники и экспорт FBX.
3. Собрать обычную сцену Unity: окружение, свет, редактируемая ракета, интерфейс, XR Origin и звуковые группы.
4. Реализовать перенос, магнитные крепления, снятие подсборок, симметрию, окраску, ступени, отмену и сохранение чертежей.
5. Реализовать движение и вращение аппарата, расход топлива, питание, нагрев, разрушение, парашюты и разделение.
6. Добавить орбиты, карту, программы выведения и возвращения, сближение и стыковку.
7. Подключить кампанию, сборку на время, рекорды и справку.
8. Проверить работу в редакторе и самостоятельном EXE. Подготовить видео, исходники, архив и публикацию Git.

## Сцена

`Assets/BRP/Scenes/Laboratory.unity` содержит ангар, сборочную платформу, ракету из отдельных объектов, освещение, интерфейс, AudioMixer и XR Origin. Основные элементы сохранены как префабы в `Assets/BRP/Prefabs`.

`BRP → Author Laboratory Scene` пересобирает сцену из исходных ресурсов. Это инструмент разработки; игра использует сохранённую сцену.

## Игровые системы

| Система | Содержание |
|---|---|
| Каталог | 50 типов, пять категорий, изображения и паспорта деталей |
| Сборка | Осевые и боковые узлы, перенос подсборок, симметрия, окраска, 6 ступеней |
| Полёт | Масса и инерция, тяга, топливо и окислитель, сопротивление и устойчивость |
| Аппаратура | Питание, солнечные панели, топливный элемент, связь, регистратор |
| Орбита | Земная гравитация, вращение атмосферы, апогей, перигей и прогноз траектории |
| Программы | Выведение, ориентация, сближение, стыковка и возвращение |
| Кампания | 20 последовательных испытаний, сохранение прогресса, повтор миссий |
| Свободный режим | Все детали, готовые конструкции, орбитальный стенд |
| VR | Захват деталей, луч для панелей, телепортация, масштабирование двумя руками, управление полётом |

## Критерии задания

| Критерий PDF | Где проверять |
|---|---|
| Исполняемый файл | `Delivery/Windows/BRP.exe` |
| Репозиторий и история | GitHub, ветка main |
| Основные детали | Каталог, эталонные конструкции, FBX и определения |
| Drag & Drop и крепления | Каталог → перенос → голубой маркер → фиксация |
| Запуск и звук | Испытать / На космодром |
| Творческая часть | Ангар, инженерные расчёты, кампания, орбитальная программа |
| Видео | `Delivery/BRP_Gameplay.mp4` |
| Исходники | Unity-проект, SourceArt, SourceAudio и Tools |

Итоговую оценку выставляет проверяющий. Состояние и результаты проверок записываются в DEVELOPMENT.md и отчётах Artifacts.
