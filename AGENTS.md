# Вектор Тяги: Лаборатория BRP

Репозиторий: https://github.com/3123412/Thrust-Vector-BRP-Laboratory.git

Пользователь требует законченную игру: Windows PC VR и ПК, 50 типов деталей, 20 миссий, свободный режим, физика полёта и орбит, видео MP4, EXE и архив исходников.

Новые комментарии в коде не писать. Коммиты на русском, с маленькой буквы, коротко: «сделал модули ракеты».

README максимально короткий, без эмодзи. Проверять humanizer-ru и slopotron.

Модели создавать в Blender через Bridge 8765. MCP Blender работает на 9876. Сторонние модели допускаются из Asset Store или через подключённый Sketchfab с подходящей лицензией.

Использовать текущий Unity 6000.6.7f1, URP, OpenXR и XRI. Не выдавать план, компиляцию или запуск редактора за проверку игры. Состояние работы и фактические проверки вести в DEVELOPMENT.md.
